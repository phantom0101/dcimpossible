A mod that attempts to make Terraria impossible, thought up by me and my friend Yeety in 2022.

Fully vibe coded with minimal manual changes to make "balance" changes.

Current effects:
* **Blood Moon every night**
* **Goblin raid every day (pre-Hardmode)**
* **Solar eclipse every day (Hardmode)**
* **All enemies 500% more HP and damage**
* **Pre-Hardmode bosses additionally 300% stronger**
* **Weapons 75% less effective**
* **Armor 75% less effective**
* **Worm AI enemies 150% faster**
* **Random lava rain**
* **Lava tsunami**
* **Evil spread 300% faster**
* **Begone Evil detection + instakill**
* **Forced Master Mode**
* **Forced Hardcore**
* **2 Moon Lords + Duke Fishron + random boss on Moon Lord summon**
* **All drops at 20% chance**
* **Every 5 minutes a random inventory item drops**
* **Random tripping while running**
* **Infinite flight tools/mounts disabled**
* **Platforms break if unreinforced**
* **Tools break on use**
* **Every 75 in-game days: all bosses spawn simultaneously**
* **Day 200: Cataclysmic Deity spawns + world conversion**
